# Английский с нуля

Telegram Mini App для изучения английского от A1 до B2: 32 модуля, 208 юнитов, 2 472 слова, грамматика, тексты с вопросами, тесты уровней и интервальное повторение. Прогресс каждого пользователя хранится в облаке Telegram.

## Как устроено

- `content/` — весь контент курса в текстовых файлах, по уровням (`a1.txt`, `a2-1.txt` и т. д.). Формат описан в начале каждого файла.
- `app.html` и `style.css` — код приложения.
- `build.py` — проверяет контент (дубли, пустые поля, варианты ответов) и собирает приложение.
- `index.html` — готовое приложение, которое публикуется через GitHub Pages.

## Обновление

```
python3 build.py
cp dist/telegram/index.html index.html
```
